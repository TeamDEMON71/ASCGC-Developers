## 📌 পোর্টফোলিও যোগ করার শর্তাবলি

ডিরেক্টরিটি পরিচ্ছন্ন ও মানসম্মত রাখতে আপনার জমা দেওয়া তথ্যকে অবশ্যই নিচের নিয়মগুলো পূরণ করতে হবে:

১. **GitHub Profile Link:** এটি আপনার সক্রিয় ব্যক্তিগত GitHub পরিচিতির লিংক হতে হবে।
২. **Portfolio Link:** এটি একটি সচল ব্যক্তিগত ওয়েবসাইট, LinkedIn পরিচিতি, Vercel/Netlify অ্যাপ, অথবা GitHub Pages সাইট হতে হবে। *(ফাঁকা বা অকার্যকর লিংক গ্রহণ করা হবে না।)*
৩. আপনাকে **আলিফ সুবহান চৌধুরী সরকারি কলেজ**-এর বর্তমান শিক্ষার্থী অথবা প্রাক্তন শিক্ষার্থী হতে হবে।

## 🚀 কীভাবে আপনার পোর্টফোলিও যোগ করবেন?

ডিরেক্টরিতে নিজের পরিচিতি যোগ করতে নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: আপনার পরিচিতির JSON তৈরি করুন

১. এই repository-টি **Fork** করুন।
২. `students/` ফোল্ডারের ভিতরে `<your-github-username>.json` নামে একটি ফাইল তৈরি করুন (যেমন: `tamim-ahmed.json`)।
৩. নিচের JSON কাঠামো কপি করে আপনার তথ্য বসান:

```json
{
  "name": "Your Full Name",
  "batch": "HSC 2024 / Session",
  "department": "Science / Arts / Commerce",
  "githubUrl": "[https://github.com/your-username](https://github.com/your-username)",
  "portfolioUrl": "[https://your-portfolio.vercel.app](https://your-portfolio.vercel.app)",
  "skills": ["HTML", "CSS", "JavaScript", "Python"]
}
```

### ধাপ ২: Pull Request জমা দিন

১. শুধু আপনার নতুন JSON ফাইলটি Commit করে `Add profile: <your-username>` শিরোনাম দিয়ে একটি **Pull Request (PR)** খুলুন।
২. আপনাকে শুধু `students/` ফোল্ডারের ভিতরে নিজের পরিচিতির JSON ফাইল তৈরি করে PR খুলতে হবে। GitHub Actions স্বয়ংক্রিয়ভাবে `README.md` এবং `README.bn.md`-এর সারণি হালনাগাদ করবে।
৩. Merge হওয়ার পর `invite-contributors` bot আপনাকে **DEMON71**-এ যোগ দেওয়ার আমন্ত্রণ স্বয়ংক্রিয়ভাবে পাঠাবে! 🎉
