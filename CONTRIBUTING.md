# ASGMC Developers - Contribution Guidelines

[ English | [বাংলা](CONTRIBUTING.bn.md) ]

Welcome to the **ASGMC Developers** community! 🎓💻 Follow these guidelines to add your developer profile and receive an invitation to join the **DEMON71 GitHub Organization** after your Pull Request is merged.

Your contribution has only two required actions: create your own `<github-username>.json` file inside `students/`, then open a Pull Request. GitHub Actions automatically updates the student tables in `README.md` and `README.bn.md`; contributors must not edit those tables manually.

---

## ✅ Mandatory Fields

Your profile file must contain both of these fields with valid, non-empty values:

- **GitHub Profile URL:** Your active personal GitHub profile, such as `https://github.com/your-username`.
- **Portfolio / LinkedIn / Vercel URL:** A functional personal portfolio, LinkedIn profile, Vercel website, Netlify app, or GitHub Pages site.

Empty, invalid, or broken mandatory links will cause the Pull Request to be rejected.

---

## 🚀 Step 1: Fork the Repository

Click the direct [Fork this repository](https://github.com/TeamDEMON71/ASCGC-Developers/fork) link to create your copy. Using this direct Fork link avoids GitHub inline editor fork redirect issues.

---

## 📁 File Naming Convention

- Place your file inside the `students/` folder.
- Use this exact format: `students/<github-username>.json`.
- The username must be lowercase and contain no spaces.
- Example: `students/tarikur-rahman.json`.

---

## 🧾 JSON Formatting Rules

- The file must use valid JSON syntax.
- Complete the `name`, `batch`, `department`, `github`, `githubUrl`, `portfolioUrl`, `skills`, and `social` fields accurately.
- Add or edit only your own profile file. Do not modify another student's file.
- Validate the JSON syntax before committing your changes.

---

## 🔀 Pull Request Guidelines

1. Use a clear PR title: `Add profile: username`.
2. Make exactly **1 file change per PR**.
3. Briefly explain your profile submission in the PR description.
4. Keep the change focused so it can be reviewed quickly.

Profiles are reviewed before merging. Once your requirements are met and your PR is merged, you will receive an invitation to DEMON71.

---

## 🚫 Don'ts

- Do not use fake or misleading links.
- Do not submit spam, duplicate profiles, or unrelated changes.
- Do not add inappropriate, offensive, or harmful content.
- Do not use another person's identity or profile.
- Do not share passwords, private tokens, or other sensitive information.

**Invalid PRs will be rejected.** Incomplete, fake, spam, or inappropriate Pull Requests will be rejected.

---

## 🆘 Need Help?

For questions or problems, open a **GitHub Issue** in the repository and include enough context and relevant links for the community to help you.

See [README.md](README.md) for the general contribution flow. 🚀
