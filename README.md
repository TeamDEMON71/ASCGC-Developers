## 📌 Requirements for Adding Your Portfolio

To keep the directory clean and high-quality, your submission **MUST** meet the following rules:

1. **GitHub Profile Link:** Must be your active personal GitHub profile.
2. **Portfolio Link:** Must be a functional personal website, LinkedIn profile, Vercel/Netlify app, or GitHub Pages site. *(Empty or broken links will be rejected)*.
3. You must be a student or alumnus of **Alif Subhan Chowdhury Govt College**.

---

## 🚀 How to Add Your Portfolio

Follow these steps to add yourself to the directory:

### Step 1: Create your profile JSON

1. **Fork** this repository.
2. Inside the `students/` folder, create a file named `<your-github-username>.json` (e.g., `tarikur-rahman.json`).
3. Copy and fill in the JSON format:

```json
{
  "name": "Your Full Name",
  "batch": "HSC 2024 / Session",
  "department": "Science / Arts / Commerce",
  "githubUrl": "[https://github.com/your-username](https://github.com/your-username)",
  "portfolioUrl": "[https://your-portfolio.vercel.app](https://your-portfolio.vercel.app)",
  "skills": ["HTML", "CSS", "JavaScript", "Python"]
}
```

### Step 2: Submit Pull Request

1. Commit only your new JSON file and open a **Pull Request (PR)** with the title: `Add profile: <your-username>`.
2. You only need to create your profile JSON file under `students/` and open a PR. GitHub Actions will automatically update the tables in `README.md` and `README.bn.md`.
3. Once merged, the `invite-contributors` bot will automatically send you an invitation to join **DEMON71**! 🎉
